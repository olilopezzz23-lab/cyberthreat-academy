# CyberThreat Academy 🛡️
> Plataforma interactiva de formación especializada en Ciberseguridad, OSINT y Cyber Threat Intelligence (CTI).

## 🚀 Características
- **3 Niveles Formativos:** Principiante, Intermedio y Profesional.
- **Formato Unificado:** Teoría técnica, laboratorios prácticos hands-on, simulador de consola interactivo y tests de autoevaluación.
- **Alojamiento Gratuito:** Compatible con GitHub Pages, Netlify, Cloudflare Pages o Vercel.

## 📂 Estructura
- `index.html`: Aplicación web interactiva completa (HTML5, Tailwind CSS, Marked.js, Lucide Icons).
- `data/cursos.json`: Base de datos de temarios, laboratorios y preguntas.
- `data/cursos.js`: Exportación compatible con ejecución local y web.
